# eIsland Shape Switching

eIsland supports two shapes: Notch shape and Dynamic Island shape.

## How to Switch Shape

### Standard Method
1. Enter the maximum expanded state
2. Click **Settings** in the **left sidebar**
3. Find the **Island Shape** option and click it to switch shapes

### Quick Method
1. Enter the maximum expanded state
2. Click **Quick Nav** in the **left sidebar**
3. Type **Island Shape** into the search box at the top right
4. Jump directly to the Island Shape settings page

### Keyboard Shortcuts
| Shortcut | Description |
|----------|-------------|
| `Alt + E` | Switch island shape |
