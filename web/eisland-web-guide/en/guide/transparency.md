# Transparency

eIsland supports transparency settings, allowing you to adjust the window opacity for better visual effects.

## View and Configure Transparency

### Standard Method
1. Enter the maximum expanded state
2. Click the **Shortcuts** option in the **left sidebar**
3. Scroll through the **right sidebar** to view different pages
4. Modify or configure shortcut combinations as needed

### Quick Method
1. Enter the maximum expanded state
2. Click **Quick Nav** in the **left sidebar**
3. Type **transparency** in the top-right search box
4. Jump directly to the transparency settings page

### Settings Location
1. Enter the maximum expanded state
2. Click **Software Settings** in the **left sidebar**
3. Scroll to the **seventh item** in the **right sidebar**
4. Scroll down to find the transparency settings
