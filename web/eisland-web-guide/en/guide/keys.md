# Keyboard Shortcuts

eIsland features a variety of built-in keyboard shortcuts with customizable settings to boost your productivity.

## View and Configure Shortcuts

### Standard Method
1. Enter the maximum expanded state
2. Click the **Shortcuts** option in the **left sidebar**
3. Scroll through the **right sidebar** to view different pages
4. Modify or configure shortcut combinations as needed

### Quick Method
1. Enter the maximum expanded state
2. Click **Quick Nav** in the **left sidebar**
3. Type **shortcuts** in the top-right search box
4. Jump directly to the shortcut settings page

## Common Shortcuts

| Shortcut | Description |
|-----------|-------------|
| `Alt + X` | Hide/Show eIsland |
| `Alt + P` | Trigger/End voice assistant |
| `Alt + C` | Close eIsland |
| `Alt + A` | Open eIsland screenshot |
| Other shortcuts | Please check in the app for more |

## Precautions

1. Some shortcuts may conflict with system or other software
2. Software restart is required after modifying shortcuts
3. Use the reset function to restore default shortcut settings
