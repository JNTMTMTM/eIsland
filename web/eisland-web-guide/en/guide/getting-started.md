# eIsland Getting Started

This article introduces the main usage of eIsland.

## Main Operations

eIsland primarily uses **mouse scroll wheel** operations. Scrolling at designated positions is more convenient than clicking.

To switch between interfaces, keep your mouse **close to the top of eIsland**, then scroll the mouse wheel to navigate between pages.

## System Requirements

<div class="tip custom-block" style="padding: 16px; border-left: 4px solid #3b82f6; background-color: #000000ff; border-radius: 4px;">
  <ul style="margin: 0; padding-left: 20px;">
    <li>Recommended OS: Windows 10 22H2 or later</li>
    <li>Memory: 8GB+ recommended, DDR4 2133MHz or higher</li>
    <li>Storage: SSD recommended for better performance</li>
    <li>Graphics: Integrated GPU may consume some system memory, please ensure sufficient RAM</li>
    <li>Compatibility issues may occur on certain platforms such as Wine translation layer, ARM platforms, etc. Please contact the developers if you encounter difficult problems</li>
