# 语音助手

eIsland 支持语音助手功能，采用了腾讯云的 ASR 服务，识别精度高，支持多语言。

##  触发方式

### 操作步骤
1. 按下键盘 `Alt + P` 触发语音助手
2. 说出您的语音指令
3. 再次按下键盘 `Alt + P` 结束语音输入
4. 语音助手会将识别到的指令显示在 eIsland 窗口中，需要用户确认后才会执行

### 前提条件
- 需要登录 eIsland 账号
- 账户余额充足

## 支持功能

语音助手可以将语音指令转换为电脑操作，包括：

- 基础操作：打开应用、关闭应用、切换窗口等
- 复杂任务：打开系统环境变量窗口并添加环境变量
- 文件操作：需要先配置工作区（见下方配置说明）

## 注意事项

1. **环境要求**：建议在安静环境中使用，嘈杂环境可能导致识别错误
2. **硬件要求**：需要正常工作的麦克风，虚拟声卡可能导致识别失败
3. **安全机制**：对于敏感操作，会立即通知用户确认授权
4. **文件操作**：需要先配置工作区才能执行文件相关操作

## 工作区配置

### 常规方法
1. 进入最大展开状态
2. 点击**左侧栏**的**AI Agent**
3. 向下滚动找到**Agent 工作区**选项
4. 添加您的工作区路径

### 快捷方法
1. 进入最大展开状态
2. 点击**左侧栏**的**快速导航**
3. 在右上方搜索框中输入**Agent 工作区**或**工作区**
4. 直接跳转到配置页面
