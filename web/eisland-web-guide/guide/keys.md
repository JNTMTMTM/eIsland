#  快捷键设置

eIsland 内置多种快捷键组合，支持自定义设置，提升操作效率。

##  查看与设置快捷键

### 常规方法
1. 进入最大展开状态
2. 点击**左侧栏**的**快捷键**选项
3. 通过滑轮切换**右侧栏**查看不同页面
4. 根据需要修改或设置快捷键组合

### 快捷方法
1. 进入最大展开状态
2. 点击**左侧栏**的**快速导航**
3. 在右上方搜索框中输入**快捷键**
4. 直接跳转到快捷键设置页面

##  常用快捷键

| 快捷键组合 | 功能描述 |
|-----------|---------|
| `Alt + X` | 隐藏/显示Eisland |
| `Alt + P` | 触发/结束语音助手 |
| `Alt + C` | 关闭Eisland |
| `Alt + A` | 开启Eisland的截图功能 |
| 其他快捷键 | 更多功能请在软件中查看 |

##  注意事项

1. 部分快捷键可能与系统或其他软件冲突
2. 修改快捷键后需要重启软件才能生效
3. 可以通过重置功能恢复默认快捷键设置
