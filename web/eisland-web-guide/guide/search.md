# eIsland 内置搜索框

在未来某些版本更新后，位置可能会发生变动，此文档不会立即更新，此时你就需要学会使用eisland的搜索框，搜索某些设置。

## 搜索框的位置

搜索框位于eIsland最大展开界面的右上角，你可以直接在搜索框中输入搜索内容，即可快速定位到相关设置。
