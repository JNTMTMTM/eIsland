#  透明度

eIsland 支持透明度设置，你可以根据需要调整窗口的透明度，以实现更好的视觉效果。

##  查看与设置透明度

### 常规方法
1. 进入最大展开状态
2. 点击**左侧栏**的**快捷键**选项
3. 通过滑轮切换**右侧栏**查看不同页面
4. 根据需要修改或设置快捷键组合

### 快捷方法
1. 进入最大展开状态
2. 点击**左侧栏**的**快速导航**
3. 在右上方搜索框中输入**透明度**
4. 直接跳转到透明度设置页面

### 设置选项位置
1. 进入最大展开状态
2. 点击**左侧栏**的**软件设置**
3. 通过鼠标滑轮切换到**右侧栏**的第七点
4. 向下翻动即可找到透明度设置
