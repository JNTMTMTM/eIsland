# Windows Volume Helper

`@eisland/windows-volume-helper` · v26.0.3

:::info
Volume query, control, and real-time monitoring for the default Windows playback device via .NET console EXE (spawnSync/spawn) backed by Core Audio COM.
:::

## API Reference

| Type | Name | Description |
|------|------|-------------|
| Function | [getMute](get-mute.md) | Get current playback device mute state |
| Function | [setMute](set-mute.md) | Set playback device mute state |
| Function | [getVolume](get-volume.md) | Get current playback device volume |
| Function | [setVolume](set-volume.md) | Set playback device volume |
| Class | [VolumeMonitor](volume-monitor.md) | Real-time volume change monitor |
