> **更新时间:** *`2026-08-05`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V26.7.0 带来全新公告系统、支付二维码、灵动岛形态切换、截图翻译、歌词卡拉OK、音量与亮度控制等多项重磅功能，同时新增网络设置、更新设置、截图设置、图片翻译历史等管理页面，并全面优化界面交互与样式体验。**

## 新功能

- 新增公告幻灯片轮播功能，支持广告展示、淡入淡出效果与导航切换。
- 新增公告社交配置功能，支持 QQ 群二维码展示与社交链接跳转。
- 新增公告视频播放功能，支持视频切换与公告列表收起联动。
- 新增公告目录导航功能，支持章节滚动定位与高亮指示。
- 新增公告头部 BILIBILI 与 GitHub 跳转按钮。
- 新增微信与支付宝扫码支付功能，支持支付状态轮询与订单分页查询。
- 新增网络设置页面，支持超时时间配置与数据中心选择。
- 新增更新设置页面，支持更新来源选择与自动更新提示配置。
- 新增截图翻译功能，支持通过灵动岛浮窗进行截图翻译，提供原文与译文对比查看。
- 新增截图工具栏，提供翻译、马赛克、画笔、矩形、区域选择等标注工具。
- 新增截图设置页面，支持截图翻译源语言配置。
- 新增图片翻译历史功能，支持历史记录分页浏览、图片预览、缩放拖拽与下载操作。
- 新增 CLI 会话检测功能，支持 Claude Code 与 Codex CLI 状态监控与生命周期管理。
- 新增系统音量控制功能，支持播放设备音量调节与静音切换。
- 新增屏幕亮度控制功能，支持 DDC/CI 协议与 WMI 双模式调节。
- 新增灵动岛形态切换功能，支持刘海模式与灵动岛模式切换，提供快捷键配置。
  - 刘海模式：经典灵动岛形态，适配顶部刘海区域，展示完整功能面板。
  - 灵动岛模式：紧凑浮窗形态，支持拖拽移动，通知与悬浮内容采用精简布局。
- 新增灵动岛引导步骤，支持形态选择预览与描述说明，帮助用户了解各形态特点。
- 新增歌词显示与卡拉 OK 功能，支持 SilkyWave 动画效果、逐行滚动与歌词源切换。
- 新增歌词字体自定义设置，支持独立配置歌词显示字体与字号。
- 新增自定义字体设置，支持 UI 界面与歌词显示分别配置字体。
- 新增音乐背景波浪预览效果。
- 新增相册缩略图加载功能。
- 新增构建体积报告工作流与 CI 部署工作流。
- 新增硬件信息查询插件注册。

- 优化设置页面布局，支持导航切换与响应式适配。
