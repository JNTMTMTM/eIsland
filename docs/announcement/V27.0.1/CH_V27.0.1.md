> **更新时间:** *`2026-11-01`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V27.0.1 全面升级计算器，新增歌曲页、Agent 用量统计、性能监控、自定义托盘菜单与灵动岛圆角样式等功能，带来 AI 对话、歌词播放、加载状态与动画过渡的多项体验优化，并大幅改善资源占用与运行稳定性。**

## 新功能

- 新增计算器复数运算与极坐标显示功能。
- 新增计算器方程求解，支持解析求解与数值求解。
- 新增计算器矩阵运算与线性方程组求解，矩阵单元格可直接编辑。
- 新增计算器函数图像，支持多曲线绘制、坐标追踪、切线分析以及定义域与值域分析。
- 新增计算器单位换算，覆盖七大类常用单位。
- 新增计算器历史记录，支持持久保存、编辑、分页浏览与公式渲染。
- 新增计算器角度单位切换、全精度 Ans 链式计算、公式与结果一键复制，以及数学错误原因提示。
- 新增歌曲页面，提供 3D 歌词滚轮、双语歌词、卡拉 OK 逐字高亮、播放进度条与音量调节。
- 新增播放进度拖动功能，可在歌词页与托盘音乐卡片中直接跳转播放位置。
- 新增 Agent 用量页面，可统计 Claude Code 与 Codex 的 Token 用量，并支持在概览页添加用量组件。
- 新增性能监控组件，可在概览页查看 CPU、内存等系统性能指标。
- 新增自定义托盘菜单，包含用户卡片、音乐控制卡片与常用菜单项。
- 新增灵动岛圆角样式设置，支持凹形刘海样式与音乐光晕效果，并在多窗口间同步。
- 新增灵动岛缩放设置，缩放比例可持久保存。
- 新增灵动岛显示与隐藏的淡入淡出过渡效果。
- 新增动画设置，修改后立即生效。
- AI 联网搜索改为接入 SearXNG。
- 新增独立的 macOS 亮度辅助插件，供开发者接入使用。

## 体验优化

- 优化 AI 对话，长对话采用虚拟列表渲染，滚动更流畅，切换会话时消息显示更稳定。
- 优化 AI 对话的加载骨架屏，并修复授权提示与模型卡片重叠的问题。
- 优化 AI 本地工具执行，避免重复请求导致工具被多次执行。
- 优化 AI 设置主题操作，确保主题在所有窗口中正确应用。
- 优化歌词页播放进度显示，展示当前歌词与更清晰的时间格式。
- 优化歌曲标题过长时的滚动显示效果。
- 优化媒体会话管理与播放进度校准，歌词同步更准确。
- 优化托盘菜单加载速度，支持后台预加载与骨架屏占位。
- 优化用户设置、壁纸市场与性能监控的加载骨架屏展示。
- 优化浅色主题下抽屉的背景与阴影效果。
- 优化灵动岛展开与收起的过渡动画，并修复动画过程中文字模糊的问题。
- 优化计算器侧边栏、工具栏、历史面板与滚动条样式，界面更统一。
- 优化登录后的会话刷新与用户资料同步，启动时自动续期登录状态。
- 优化安装与升级流程，更可靠地检测并结束占用中的进程。
- 优化更新服务与更新通知的处理。
- 优化邮件加载，先获取邮件摘要，正文按需加载。
- 优化相册浏览，大量图片时采用虚拟化展示，并降低媒体缓存占用。
- 优化聊天记录加载，按需读取会话历史并独立保存流式对话进度。
- 优化窗口隐藏时自动暂停动画与背景视频，降低资源占用。
- 优化提醒调度方式，到点触发而不再持续轮询。
- 优化音量、亮度、媒体与进程检测等后台服务，减少卡顿与资源占用。
- 优化独立窗口页面按需加载，提升启动速度。
- 简化闹钟设置与声音设置的描述文案。
