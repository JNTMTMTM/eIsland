> **更新时间:** *`2026-08-06`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V26.7.1 新增多显示器截图支持与截图引擎选择，并带来 QQ 群邀请与反馈历史等实用更新，同时修复了屏幕亮度与音量控制在 Electron 打包环境下的兼容性问题。**

## 新功能

- 新增多显示器截图支持，可同时捕获所有显示器画面并保存为图片。
- 新增截图引擎选择与配置选项，用户可根据需要切换不同的截图方式。
- 新增 QQ 群邀请功能，用户可在关于页面中查看并加入官方 QQ 群。
- 新增反馈历史页面，用户可查看历史反馈记录。

## 体验优化

- 优化截图捕获逻辑，提升不同环境下的截图稳定性。
- 优化虚拟屏幕边界计算方式，多显示器场景下的计算效率更高。
- 优化 QQ 群配置的获取方式，增强错误处理与异常提示。
- 简化 QQ 群配置结构，移除冗余的二维码图片地址字段。
- 优化 QQ 群按钮样式与布局，展示更清晰。
- 优化环境相关 API 地址处理逻辑，适配更规范。

## 问题修复

- 修复屏幕亮度调节辅助工具在 Electron 打包环境下无法正常加载的问题，新增旧版兼容回退机制。
- 修复音量控制辅助工具在 Electron 打包环境下无法正常加载的问题，新增旧版兼容回退机制。
- 修复开发环境下渲染进程窗口检测可能报错的问题。
- 修复 API 基础地址在不同环境下未正确切换的问题。
