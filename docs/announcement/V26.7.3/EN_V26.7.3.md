## New Features

- Added scientific calculator module with formula input, function evaluation, and scientific operations.
- Added calculator coordinate graph component with function plotting, dynamic zooming, and axis display.
- Added KaTeX formula rendering for the calculator, providing high-quality math expression typesetting and interactive cursor positioning.
- Added Qishui Music third-party login support via QR code authorization.
- Added music lyrics scrolling component with per-character scrolling and karaoke progress effects.
- Added extension management functionality for installing, updating, and version managing extensions.
- Added extension management settings page for viewing and managing installed extensions.
- Added ESA CDN cache purging functionality to optimize extension distribution and update speed.
