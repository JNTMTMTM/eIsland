> **更新时间:** *`2026-11-09`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V27.0.2 将 Windows 桌面版迁移至 Tauri，提供独立的迁移助手，支持升级前备份、自定义安装目录和旧版卸载选择，并改进歌词同步、截图及系统媒体控制。**

## 新功能

- Windows 桌面版切换至 Tauri，沿用灵动岛界面与现有功能入口。
- 新增旧版迁移助手，升级前创建并校验独立备份，保留原有数据。
- 迁移时可选择新版安装目录，并决定是否在安装成功后打开旧版卸载程序，默认保留旧版。
- 工具箱新增音视频轨道提取，可将音频或视频单独保存到指定位置。
- 音乐播放器白名单新增 YouTube Music 支持。
- 命令行工具新增交互式任务面板，支持并发任务、输出查看与脚本执行确认。
- 命令行工具支持查看已保存的数据，并可确认后删除指定条目。

## 体验优化

- 迁移助手将 ESA 加速、Cloudflare R2 和 GitHub 下载源改为独立按钮，便于直接切换。
- 调整迁移向导的布局、按钮图标和错误提示，错误提示可关闭并返回上一步。
- 改进迁移助手的语言菜单，支持中文、繁体中文、英语和日语切换及键盘操作。
- 改进截图功能与截图设置，使用 Windows 原生截图支持。
- 改进窗口层级与特效显示，减少灵动岛、阴影和独立窗口之间的遮挡问题。
- 改进媒体会话识别与播放状态同步，暂停播放时同步暂停歌词动画。
- 关闭歌词翻译后减少不必要的翻译请求。
- 改进系统音量、屏幕亮度和快捷键处理。
- 更新时校验安装包签名，下载不完整或校验失败时中止安装。

## 问题修复

- 修复部分歌词中的纯符号行、标点和逐字时间信息解析不完整的问题。
- 修复部分情况下文件拖放目标未正确注册的问题。
- 修复部分文件图标读取失败的问题。
- 修复目录别名和目录链接导致的备份路径判断错误，阻止将备份保存到原数据目录内。
- 修复旧版卸载程序尚未结束就提前检查卸载结果的问题。
- 修复迁移助手缺少正式更新公钥时仍尝试下载或安装的问题。
- 修复部分更新源下载地址和文件路径不一致导致的更新失败。
