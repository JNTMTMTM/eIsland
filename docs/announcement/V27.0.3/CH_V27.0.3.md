> **更新时间:** *`2026-11-18`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V27.0.3 新增文件中转站与歌词功能开关，将音量、亮度、截图、全屏检测和硬件温度改为内置实现，并改进纯音乐识别与暂停后的歌词状态恢复。**

## 新功能

- 新增文件中转站：把文件拖到灵动岛即可暂存，可再拖出到其他应用、直接打开或在文件夹中显示。
- 设置 → 音乐 → 歌词新增「启用歌词功能」开关，关闭后不再请求歌词，灵动岛改为显示歌名。
- 汽水音乐识别为纯音乐时显示「纯音乐，请欣赏」，不再向其他歌词源重复请求。
- 截图时可点击鼠标右键直接取消。
- 智能助手可按需查阅内置功能说明，回答使用问题更准确。

## 体验优化

- 系统音量、屏幕亮度、截图、全屏检测和硬件温度读取改为内置实现，无需再安装额外扩展。
- 截图窗口在画面准备好后再显示，减少打开截图时的闪烁与等待。
- 未获取到歌词时，灵动岛以前奏样式显示歌名，不再直接回到空闲状态。
- 纯音乐提示会随界面语言切换，且不再触发歌词校准。
- 性能模式下拖入文件时立即显示文件中转站。
- 更新安装程序与卸载程序图标。
- 移除 Mimo 和 MiniMax 模型选项。

## 问题修复

- 修复暂停播放后从歌词状态进入悬停、再移开鼠标会回到空闲状态而不是原歌词状态的问题。
- 修复按 Esc 离开悬停时总是回到空闲状态的问题。
- 修复部分自定义字体无法加载的问题。

## 文档更新

- 移除已下线扩展的相关文档，并更新开发规范与合并方式说明。
