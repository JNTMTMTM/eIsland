> **更新时间:** *`2026-10-09`*
> **代码仓库:** [`https://github.com/JNTMTMTM/eIsland`](https://github.com/JNTMTMTM/eIsland)

**V27.0.0 新增应用导航模式、日历与世界时钟，扩展概览页闹钟管理，带来待办清单、倒计时、主题切换与性能模式的多项体验优化，并修复歌词显示、搜索结果、音乐登录与闹钟触发等问题。**

## 新功能

- 新增应用导航模式，可通过图标网格进入各功能页面，支持长按拖拽排序与拖入隐藏区域隐藏入口。
- 新增日历，支持连续滚动浏览、月视图与年概览切换，以及一键返回今天。
- 新增日历日期详情，可查看农历、所选地区的节假日、待办事项与倒计时事件。
- 新增世界时钟，支持城市选择、多时区时间展示与模拟时钟显示。
- 新增概览页世界时钟组件，支持双时区配置并可直接打开世界时钟页面。
- 新增概览页闹钟组件，可查看闹钟状态并快捷进入闹钟管理。
- 新增胶囊模式位置锁定功能，方便固定灵动岛的显示位置。
- 新增独立的 macOS 媒体辅助插件，提供当前播放信息、封面、播放进度、状态监听与媒体控制接口，供开发者接入使用。

## 体验优化

- 优化待办清单，支持为任务设置截止日期，并可直接编辑任务与子任务标题。
- 优化待办详情布局与展开动画，任务描述、子任务和删除操作更加清晰。
- 优化倒计时编辑面板，调整背景、边框与颜色配置布局，改善卡片和日历中的选中反馈。
- 优化闹钟时间选择器的滚动与拖动体验，并完善闹钟同步失败提示。
- 优化应用导航的悬停、长按与拖拽反馈，调整大屏布局和页面切换动画。
- 优化工具箱导航，保存入口排序与显示配置，并在保存失败时提供提示。
- 优化主题切换动画与展开内容过渡，完善性能模式下的加载反馈。
- 优化灵动岛窗口尺寸适配与拖动交互，改善展开页面的显示效果。
- 优化天气自定义坐标定位，补齐所在地区与国家信息。
- 调整市场入口分类与设置页面布局，改善不同窗口尺寸下的显示效果。

## 问题修复

- 修复部分逐字歌词自动解析时音节信息丢失的问题。
- 修复歌曲标题包含特殊 Unicode 字符时截断显示异常的问题。
- 修复 Spotify 歌词获取在特定认证密钥长度下失败的问题。
- 修复重复闹钟跨日期触发与下一次响铃日期计算异常的问题。
- 修复计算器显示长数字时错误裁剪整数位或科学计数法指数的问题。
- 修复连续发起本地文件或股票搜索时，较早的结果覆盖最新结果的问题。
- 修复刷新音乐登录二维码或切换登录状态时，旧请求干扰当前界面的问题。
- 修复语音转文字复制失败后的反馈与重试问题。
- 修复收藏缓存中部分异常数据导致有效收藏记录被丢弃的问题。
- 修复停止性能监控后，尚未完成的采集结果重新显示的问题。
- 修复 AI 对话初始化与工具执行结果处理中的异常问题。
- 修复覆盖安装时对运行中应用的识别问题，完善安装前的进程检查。
- 修复 F11 默认全屏快捷键破坏灵动岛窗口布局的问题。
