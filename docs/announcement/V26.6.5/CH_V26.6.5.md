**V26.6.5 新增 URL 收藏管理、邮件收发、备忘录编辑、本地文件搜索、待办清单、倒计时与剪贴板历史共 7 个全新功能模块，同步扩展 Gitee 与 KOOK 第三方登录支持，并带来相册浏览与多项交互体验优化。**

## 新功能

- 新增 Gitee 第三方登录支持，可在登录界面与用户设置中选择 Gitee 账号授权登录。
- 新增 KOOK 第三方登录支持，可在登录界面与用户设置中选择 KOOK 账号授权登录。
- 新增 微信 第三方登录支持，可在登录界面与用户设置中选择 微信 账号授权登录。
- 新增 微软 第三方登录支持，可在登录界面与用户设置中选择 微软 账号授权登录。
- 新增 GitHub 第三方登录支持，可在登录界面与用户设置中选择 GitHub 账号授权登录。

## 体验优化

- 重构 URL 收藏管理模块，支持收藏的添加、编辑、删除与搜索，提供拖拽排序与导入导出功能。
- 重构邮件模块，支持多账户收件箱管理，提供邮件列表浏览与邮件详情阅读功能。
- 重构备忘录模块，支持备忘录的创建、编辑、删除与搜索，提供侧边栏导航与空状态引导。
- 重构本地文件搜索模块，支持本地文件检索与配置管理，提供搜索结果展示与过渡动画效果。
- 重构待办清单模块，支持任务的创建、编辑与管理。
- 重构倒计时模块，支持倒计时事件的创建与管理，提供日历视图与卡片展示。
- 重构剪贴板历史模块，支持剪贴板记录的查看与管理，提供展开模式与详情展示。
- 重构相册浏览模块，支持相册图片的网格展示、元数据查看与批量选择操作。
- 优化本地文件搜索配置面板的过渡动画与布局效果，交互更流畅。
- 优化相册组件的文件处理与数据管理，操作响应更灵敏。
- 优化备忘录编辑器的界面布局与过渡效果，编辑体验更自然。
- 优化登录面板宽度适配，界面展示更协调。

## 问题修复

- 修复登录面板宽度不足导致的布局问题。
- 修复相册浏览组件中背景媒体预览地址的导入路径错误。
- 修复邮件模块初始化时的竞态条件，避免快速切换账户时旧请求覆盖新账户数据。
